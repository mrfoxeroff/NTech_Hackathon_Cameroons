# Данные известной сцены

- `automatic-candidates.json` — сохранённые автоматические предложения SceneAligner и геометрического поиска.
  Входом не были ручные `cam_*_calibration.json`. Численные матрицы — данные модели, а не условия `if` с координатами комнат.
- `lenses.json` — оценки параметров камер GeoCalib.
- `source-manifest.json` — контрольные суммы исходных записей, для которых построены предложения.
- `plan.jpg`, `plan-walls.png`, `floor/` — схема и автоматически полученные маски сцены.
- `clock-templates/` — шаблоны фиксированного OSD прежней проверки синхронизации; разметка цифр часов не является разметкой плана.

Это кэш конкретного офиса. Он позволяет воспроизвести геометрический этап без многогигабайтных весов реконструкции.
Кэш не означает надёжно найденное место. Другой объект или изменённая камера потребуют новых автоматических предложений.
