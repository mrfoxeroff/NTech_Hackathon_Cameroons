# Воспроизводимый пример

`pairs.json` содержит предложения соответствий из реального пилота, уже после извлечения признаков и фильтров.
Из него убраны пути к локальным изображениям и сами кадры. Глобальные ID готового трекера не использованы.
Наблюдения помечены `train`/`holdout`; проверочные координаты не участвуют в подгонке.

Команда `python homography_lab/demo.py --output ...` использует эти предложения и автоматический банк сцены.
Это повтор геометрии по кэшу, а не новый анализ видео. Результат остаётся отклонённой исследовательской гипотезой.
