# Аудит треков пяти камер

Сравнение выполнено на одной записи продолжительностью 20:04. У обоих
экспортов один набор из 27 185 локальных наблюдений. Для каждого из 281
исходных ID просмотрены начало, середина и конец, где эти точки доступны.
Для межкамерных треков в контактные листы добавлен ещё один ракурс. Это
просмотр контрольных кадров каждого трека. Покадровой эталонной разметки
людей и полного измерения precision, recall или IDF1 пока нет.

## Причины и изменения

- На камерах 1–2 короткие ID часто возникали у края изображения. На камере 4
  в трек иногда выделялись ноги или часть корпуса. Одной уверенности
  детектора было недостаточно для выдачи отдельного ID.
- На камерах 3 и 5 дальние маски могли захватывать голову или торс,
  особенно у двери. Для нового одиночного дальнего трека теперь нужны
  2,85 секунды связной видимости и девять наблюдений с уверенным силуэтом.
  Для обычного одиночного трека пороги 1,75 секунды и пять наблюдений.
  Подтверждение учитывает обрезку кадром и видимость опорной точки.
  Отдельные вспышки до 0,5 секунды из одной камеры исключаются из
  активных интервалов уже подтверждённого ID.
- При встречном движении и закрытии одного человека другим обнаружены
  четыре дополнительные смены личности. Например, на камере 3 около
  05:32 локальный ID 63 перескочил с человека в тёмной одежде на человека
  в белом. Около 15:59 локальный ID 137 сменил человека в однотонной
  одежде на человека в полосатой. Для разрыва теперь нужны устойчивые
  исходные признаки, резкое изменение внешности и другой человек рядом.
- Межкамерная проверка использует синхронные положения и направление
  движения. Слабые признаки внешности в коридоре могут подкрепляться
  двумя независимыми ракурсами в одном временном интервале. Десять
  дополнительных связок сверены по кадрам. Например, прежние 180, 181
  и 182 составляют один проход по камерам 4, 3 и 5 около 07:50–08:05.

Проверка ранее исправленных эпизодов сохранена. На девяти контрольных
моментах между 01:38 и 02:33 человек в дальнем коридоре имеет ID 8,
соседний человек имеет ID 10. В эпизоде толпы человек в синих джинсах
имеет ID 14, человек в белой футболке имеет ID 11. Номера относятся к
экспорту со 125 треками.

## Общая 2D-шкала

Новый экспорт сохраняет `world_state.json`. Запрос
`GET /api/state?t=98` возвращает подтверждённые ID в 120-миллисекундном
окне общей шкалы, их координаты в пикселях плана и исходные кадры с
точными временами. Карта плеера строится из того же набора состояний.
Если проекции согласованы, используется устойчивая оценка по нескольким
ракурсам. При противоречии, которое нельзя разрешить по предыдущему
наблюдению, поле `position` равно `null`. В пробелах наблюдения
позиция не достраивается.

Проекции камер 3 и 5 остаются наиболее чувствительными к геометрии
коридора. В итоговом аудите около четверти пар опорных точек одного ID
на этих камерах расходятся больше чем на 24 пикселя плана при допуске
по времени 150 мс. Это измерение согласия проекций, на него влияют
калибровка, перекрытия и точность опорной точки. Общая шкала следует
экранным часам, независимого измерения субсекундной синхронности
момента съёмки нет.

## Возврат через дверь и дальний ракурс

Около 00:25–00:28 прежние ID 5 и 6 описывали одного человека на
камерах 3 и 5. На камере 3 локальный трек разделился в момент
перекрытия, хотя маски силуэта совпали на общем кадре. Два локальных
фрагмента теперь связаны с одним глобальным ID 5. Если одна камера
оценивает положение скрытых ног, а другая видит точку опоры, карта
использует наблюдаемую точку. Порог confidence оставлен прежним.
Даже при уверенности 0,85–0,93 камера 3 могла ошибаться в точке опоры.

Для подтверждённого возврата окно в 60 секунд включительно отсчитывается
от последнего появления человека на любой камере. Сопоставление учитывает
положение возле двери и несколько наблюдений внешности. Если на ID
претендуют сопоставимые кандидаты, он остаётся свободным. После
подтверждённого возврата окно начинается заново при следующем исчезновении.
Пока человек вне поля зрения, его текущая позиция и активный ID
отсутствуют на плане и в API.

На всех пяти камерах повторно проверены контрольные эпизоды. Семь
возвратов сверены по кадрам, самый длинный перерыв составил 59,914
секунды. В обновлённом экспорте 118 подтверждённых треков вместо 125.
Номера других треков могли измениться при повторном экспорте.

