# Проверка перед публикацией

Дата: 2026-11-07. Проверялся модуль этой ветки, отдельно от исходного локального архива.

| Проверка | Результат |
|---|---|
| Чистое окружение только с `requirements-core.txt`, без PyTorch и моделей | 69 тестов и пример прошли |
| Полный доступный набор лаборатории | 103 теста прошли |
| Основной трекер, `python -m pytest -q` из корня | 116 тестов прошли |
| Архивные межкамерные модули, `python -m pytest -c mtmc/pytest.ini mtmc -q` | 141 тест прошёл |
| Ruff для лаборатории | Замечаний нет |
| Целостность включённых ресурсов | Проверены SHA-256 всех 41 файла манифеста |
| Повтор геометрии из кэша | Медиана 4.6679 px на 8 предложенных проверочных парах; экспорт пуст |
| Проверка входов полного запуска | Все внешние ресурсы найдены при явном указании локальных каталогов |
| Запуск моделей на реальных кадрах | По одному кадру камер 1–3: YOLO Pose, OSNet, Intel ReID и SegFormer отработали |

Основной трекер проверен с его закреплённой версией Ultralytics 8.4.203;
лаборатория — с отдельным окружением Ultralytics 8.3.200 / OpenCV 4.13.
Архивные межкамерные тесты выполнены в прежнем окружении Python 3.10;
основной трекер и лаборатория — Python 3.12.
Наборы частично пересекаются, складывать их количества в число уникальных проверок нельзя.

Проверка трёх кадров подтверждает запуск перенесённых моделей, а не качество или скорость обработки всех записей.
Полная обработка 1876 кадров относится к исходному пилоту, описанному в [отчёте](reports/motion-office/RESULTS.md).
После переноса заново выполнена геометрия этого пилота и короткая проверка моделей; все видео повторно не обрабатывались.

Улучшение межкамерной согласованности не подтвердило правильность места на плане.
Абсолютная привязка остаётся нерешённой; рабочие калибровки и глобальные ID основного проекта не заменяются.
Для дальнейшего развития нужны независимые проверки места по проходам, стенам и траекториям,
а затем новый контрольный набор, который не использовался при разработке.

GitHub Actions запускает минимальный переносимый набор и пример без нейросетей.
Наличие файла workflow само по себе не означает, что удалённая проверка уже завершилась успешно.
