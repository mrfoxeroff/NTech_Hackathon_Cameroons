# Статичные образцы и контуры предметов

Для каждой из пяти камер извлечён настоящий кадр исходного видео в разрешении
2592 × 1944. Контрольные точки полигонов выбраны ассистентом после визуального
просмотра; отрисовка, маски и проверка файлов выполнены средствами OpenCV,
декодирование — PyAV. Генеративные изображения не использовались.

## Файлы

- `camera_N.jpg` — исходный кадр без линий.
- `camera_N.annotated.jpg` — тот же кадр с цветными контурами, полупрозрачной заливкой и номерами объектов.
- `camera_N.review.jpg` — обзор с легендой номеров справа; координаты JSON относятся к оригиналу, не к этой обзорной картинке.
- `camera_N.json` — полигоны в формате LabelMe; координаты в пикселях оригинала, `group_id` объединяет части одного объекта.
- `camera_N.mask.png` — объединённая бинарная маска всех размеченных предметов, 0/255.
- `camera_N.instances.png` — 16-битная маска: 0 — фон, другие значения — номера объектов внутри камеры. При пересечении полигонов здесь остаётся последний нарисованный объект.
- `masks/camera_N/NNN.png` — самостоятельная бинарная маска объекта; сохраняет его полностью даже при пересечении с другим полигоном.
- `sources.json` — исходные файлы, номера кадров и время.
- `summary.json` — количество объектов и компонент полигонов.
- `validation.json` — результат проверки координат, пересечений и масок.
- `overview.jpg` — общий обзор всех пяти размеченных кадров.

Объекты: игровые столы с ножками, кресла, растения, выставочные конструкции,
светильники, шторы, огнетушитель, вешалка/стойка, дверные ручки и небольшие предметы.
Экраны (`screen`), зеркало (`mirror`) и плакат (`poster`) размечены отдельно как
возможные источники визуальных ложных срабатываний. Остальные объекты имеют класс
`furniture` в широком смысле, заданном пользователем. Названия предметов находятся
в `description` полигонов и в `annotation_metadata.objects`.

Всего: 69 объектов, 120 полигональных компонент. Номера объектов локальны для камеры;
одинаковые номера разных камер не обозначают один физический предмет.

## Точность и назначение

Это приблизительные контуры видимых частей статичных предметов. Мелкие выступы,
листва и тонкие опоры упрощены; скрытые части не восстанавливались.
Разметка не является пиксельно точной эталонной сегментацией.

Это разметка предметов сцены, а не обучающий датасет `person`: на кадрах камер 3 и 5
видны люди, но люди здесь не размечены. Эти кадры нельзя объявлять пустыми
отрицательными примерами при обучении детектора людей.

Маску предметов нельзя безусловно использовать для удаления людей: человек может
пройти перед мебелью, закрыть её или сесть в кресло. Контуры могут служить контекстом
для фильтрации кандидатов и подготовки дообучения, но сами по себе не исправляют
модель. Текущий конвейер трекинга не изменён, обучение не запускалось.

Повторное создание из корня проекта:

```powershell
.\.venv\Scripts\python.exe tools/prepare_scene_samples.py
```

Видео и содержимое `data/` исключены из Git действующим `.gitignore`.
