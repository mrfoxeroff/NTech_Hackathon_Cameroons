# Автоматическая нейросетевая привязка

Это отдельный экспериментальный путь. Он не читает вручную расставленные пары
или готовые гомографии камер офиса. Пользователь передаёт изображения камеры
и схему, подготовленные командой `prepare`. Ручных кликов по опорам нет.

## Конвейер

1. Фон неподвижной камеры получается из нескольких кадров видео.
2. Готовая SegFormer B0 ADE20K выделяет пол. Класс определяется по именам меток
   модели, а не по заранее заданному номеру. Пол нужен для отделения столов,
   стен и потолка: их проекции не принадлежат одной плоскости с ногами человека.
3. Готовая C3Po получает пару «план + фото» и предсказывает плотное соответствие
   пикселей фотографии координатам плана. Сопоставление обучено для этих разных
   типов изображений; это отличается от SIFT-поиска одинаковой текстуры.
4. Из предсказаний автоматически выбираются пространственно распределённые
   точки пола. Повторяющиеся координаты и выходы за изображения исключаются.
5. RANSAC оценивает матрицу. Часть сетевых предсказаний откладывается для проверки
   геометрической согласованности. При недостаточном числе точек, вырожденной
   конфигурации или большой ошибке гипотеза отклоняется.

Источники:

* [Официальный C3Po](https://github.com/c3po-correspondence/C3Po),
  код `21254a078435451e99d2feabd5db9334c02d8483` и его CroCo-submodule.
* [C3 — датасет фото и планов](https://huggingface.co/datasets/kwhuang/C3).
* [SegFormer B0 ADE20K](https://huggingface.co/nvidia/segformer-b0-finetuned-ade-512-512).
* [SceneAligner](https://github.com/Cornell-VAILab/SceneAligner) — альтернативный
  исследовательский путь через восстановление 3D и совмещение с планом;
  в данном прототипе он не запускался.

## Что означает результат

`automatic_candidate` — сеть дала достаточно согласованную геометрическую
гипотезу. Это **не независимое доказательство физической точности**: отложенные
предсказания принадлежат той же модели. В отчёте явно указаны
`validation_source=held_out_predictions_of_same_network` и
`physical_accuracy_verified=false`.

Модель может согласованно выбрать не ту комнату на повторяющемся плане.
Неизвестный рост объектов, зеркала и дисторсия также влияют на сопоставление.
Выходящие из одной точки предсказания не создают калибровку: такие случаи
отклоняются. Успешное завершение программы не означает успешную локализацию.

Калибровка `automatic_candidate` по умолчанию не принимается консервативной
командой `app.py project`. Для исследовательского просмотра допускается
`--allow-draft`. Интеграции с готовым трекером нет.

## Установка и файлы

Рабочий трекер не изменяется. Новые зависимости находятся в `neural_deps`,
сторонний код — в `vendor/C3Po`, веса — в `neural_weights`. Эти каталоги исключены
из Git. Лицензии стороннего кода и весов сохраняются в их исходниках; код
DUSt3R/CroCo содержит ограничения на коммерческое использование.

Официальный C3Po checkpoint содержит примерно 10,24 ГБ, включая состояние
обучения. Архитектура имеет около 873 млн параметров. Для инференса используется
только `model`, загрузка файла выполняется с `weights_only=True`, mmap и явной
архитектурой без исполнения строки модели из checkpoint.

На этой машине обнаружена RTX 2060 6 ГБ, но установленный рабочий PyTorch — CPU.
Первый эксперимент выполняется на CPU. Рабочий PyTorch автоматически не заменяется.
Условия запуска CUDA и достаточность 6 ГБ для этой модели отдельно не проверены.
Обучение на нашем офисе не выполняется.

## Автоматический запуск

Из корня рабочей папки, после подготовки сеанса и загрузки моделей:

```powershell
& './mtmc/.venv/Scripts/python.exe' homography_lab/neural_auto.py `
  --session homography_lab/runs/office-01 `
  --output homography_lab/runs/neural-c3po-repeat --device cpu
```

Для первой загрузки публичной SegFormer есть отдельный флаг `--allow-downloads`.
Обычно её веса уже находятся в локальном кэше прототипа. Модель C3Po скачивается
по ссылке checkpoint из официального README; стандартный путь —
`homography_lab/neural_weights/C3Po.pth`.

Для просмотра результата:

```powershell
& './mtmc/.venv/Scripts/python.exe' homography_lab/neural_viewer.py `
  --output homography_lab/runs/neural-c3po-repeat --port 8766
```

Открыть <http://127.0.0.1:8766>. Это просмотр нейросетевого результата без
редактора ручных опор. Новый выходной каталог обязателен для каждого запуска.

Файлы:

* `manifest.json` — статус запуска, состояние каждой камеры, причины отказа.
* `cam_N-floor.png` — автоматически выделенный пол.
* `cam_N-dense.npz` — плотное предсказание соответствий нейросети.
* `cam_N-pairs.json` — автоматически полученные пары и их происхождение.
* `cam_N-calibration.json` — матрица с явным статусом, если её удалось вычислить.
* `cam_N-matches.jpg` — визуальное сопоставление предсказаний с планом.

Проверки без загрузки весов и нейросетевого инференса:

```powershell
& './mtmc/.venv/Scripts/python.exe' -m pytest -q -p no:cacheprovider homography_lab
```

22 теста проверяют математический и программный путь. Четыре дополнительных
нейросетевых теста проверяют пересчёт letterbox-координат, автоматический выбор
пар, ограничение точками пола и отказ при схлопывании предсказаний. Они используют
синтетическую плотную карту и не измеряют качество обученной C3Po на офисе.


## Результат на наших двух камерах

Реальный запуск: `runs/neural-c3po-office/`. Ручных пар на входе нет.

| Камера | Предсказанные пары | Проверка геометрии | Итоговая проверка |
|---|---:|---|---|
| cam_1 | 29 | 16/21 обучающих согласованы, максимум на 8 отложенных предсказаниях 7,04 px | Визуально выбрана неверная область плана; привязка непригодна |
| cam_2 | 54 | 25/40 согласованы, максимум на 14 отложенных предсказаниях 21,63 px | Автоматически отклонена |

Указанные ошибки — согласованность предсказаний одной сети, **не ошибка истинной
позиции человека**. Инференс соответствий на CPU занял 17,9 и 14,3 секунды
соответственно, без времени загрузки checkpoint и сегментации пола.

Дополнительно проверены четыре перекрывающихся фрагмента схемы для камеры 1:
`runs/neural-crop-search-cam1/trials.json`. Все четыре гипотезы отклонены.
Координаты фрагментов выбирались общим правилом 65% размеров плана, без знания
положения конкретной камеры. Готовые гомографии офиса в этот поиск не поступали.

**Автоматическая расстановка нейросетью реализована; пригодная автоматическая
калибровка этого офиса пока не получена.** Следующее исследовательское направление —
адаптация модели к офисным планам или восстановление 3D из нескольких ракурсов
с последующим сопоставлением структуры с планом. Оно ещё не реализовано.
Проверку модели нельзя заменять повышением допуска RANSAC.

Результат визуального контроля хранится отдельно в `evaluation.json`, не
используется при предсказании и не меняет сырые выходы модели. Просмотрщик
учитывает отрицательный результат, а не объявляет согласованную гипотезу
проверенной реальной калибровкой. Основной репозиторий не изменён.
